# Abondy — landing page recreation

Responsive static recreation inspired by the supplied Abondy website capture. Built with plain HTML and CSS for direct Vercel deployment.

## Run locally
Open `index.html` in a browser or use any static file server.

## Deploy
Import this repository into Vercel. No build command is required; set the output directory to `.`.

This independent demonstration is not affiliated with Abondy. Product links lead to the original website.
